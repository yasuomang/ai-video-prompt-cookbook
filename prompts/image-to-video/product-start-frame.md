# Product Start Frame to Video

Use this when you already have a clean product image and want a short motion clip.

```text
Subject: [product name or description] placed on [surface/background].
Input type: start frame / product image.
Camera movement: slow push-in toward the product.
Motion description: soft light moves across the product while the product stays stable.
Style: clean product advertisement, realistic, minimal.
Duration: [5-8 seconds].
Aspect ratio: [9:16 / 16:9 / 1:1].
Preservation constraints: keep the product shape, label, color, logo, and position unchanged.
Negative constraints: no extra objects, no label distortion, no background replacement.
Evaluation notes: check label readability, product shape stability, and motion smoothness.
```

## Common Fixes

| Problem | Fix |
| --- | --- |
| Product shape changes | Add stronger preservation constraints |
| Camera moves too fast | Use "slow push-in" or "locked camera" |
| Label becomes unreadable | Avoid relying on small generated text |
