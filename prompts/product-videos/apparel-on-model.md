# Apparel On-Model Video

```text
Subject: a model wearing a [beige linen shirt].
Input type: start frame / on-model photo.
Camera movement: medium-wide, slow backward tracking.
Motion description: the model walks toward camera on a sunlit street, turns to look over the shoulder; fabric moves lightly in the breeze.
Style: Mediterranean summer light, soft film tones, fashion lookbook.
Duration: 5 seconds.
Aspect ratio: 9:16.
Preservation constraints: keep the garment color, cut, pattern, and buttons unchanged.
Negative constraints: no outfit changes, no extra accessories, no face distortion during the turn.
Evaluation notes: check garment fidelity (especially patterns and collars) and face stability on the head turn.
```

## Variation

For a flat product page clip, use a ghost-mannequin image as the start frame and ask only for `fabric moves gently as if in a light breeze, camera locked off`.
